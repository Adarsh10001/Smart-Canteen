# Smart Canteen Management System

## About
A Java-based desktop application built using Java Swing and MySQL to simplify canteen management.

## Features
- Student registration and login
- View available menu items
- Place orders with simulated UPI payment
- View order history
- Admin menu management
- Admin order management and status updates

## Technologies Used
- Java
- Java Swing
- MySQL
- JDBC

## Setup Instructions
1. Install Java JDK and MySQL.
2. Create a database named `smart_canteen`.
3. Execute the provided SQL script to create the required tables.
4. Update the database connection settings in `DBconnection.java`.
5. Add the MySQL JDBC driver to the project.
6. Run `Main.java` to start the application.
